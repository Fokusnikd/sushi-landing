# Первый экран: керамическая тарелка

- `components/Hero.tsx` лениво подключает `three/Hero3D.tsx` через Suspense. Сохраняет тёплый фон, появление композиции и неподвижные плашки; фотография убрана.
- `Hero3D.tsx`: профилированная матовая тарелка цвета слоновой кости, три ролла Philadelphia, складчатые лепестки имбиря и рифлёный васаби. Использует `SoftRoll` и общий `Lights` из `SushiModel.tsx`; модели студии из `parts.tsx` независимы.
- `SoftRoll.tsx`: лёгкая мультяшная стилизация, скруглённый квадратный срез вдоль Z, пастельный лосось с четырьмя геометрическими прожилками, кольца риса и нори, кремовая начинка и огурец. Рис — 144 инстанса на ролл, по два ряда на обеих сторонах. Геометрия процедурная, без растровых текстур. Высота центра и ширина захвата в Hero3D связаны с размерами SoftRoll.
- `platePose` задаёт цикл 11 с: подход, захват, подъём 0.85 единицы, пауза, опускание, раскрытие и отход. Палочки смыкаются до подъёма, раскрываются только после возвращения ролла. Наконечники захватывают верхний край, наклонные стержни не идут через середину ролла.
- Указатель плавно поворачивает всю композицию в пределах 0.12 радиана по Y и 0.035 по X. Touch не управляет поворотом. При reduced motion используется неподвижная поза; вне экрана цикл не продвигается, Canvas работает в demand. DPR до 1.5, локальное световое окружение и PCF-тени.
- `public/textures/salmon.webp` сохранена от предыдущей версии; текущая сцена её не использует.
- Проверки 2026-10-05: build и lint прошли; новые модели проверены в браузере на широком и узком экране, ошибок консоли нет. Движение палочек видно в последовательных кадрах. Численная проверка двух циклов с шагом 0.01 с: захват замкнут во время подъёма, hover равен нулю, подъём в пределах 0–0.85. Низ ролла 0.120, поверхность тарелки 0.110. Reduced motion сохранён по ветке кода, системная настройка не переключалась.
- Vite предупреждает о крупном three.js chunk; он загружается отдельно. Студия продолжает использовать свои модели, визуально в этой задаче не проверялась.
