# «Суши для Андрюши» — демо-лендинг

Демо-проект для портфолио: лендинг доставки суши. Ресторан вымышленный, цены и отзывы придуманы, заказы никуда не отправляются.

## Моушн-графика

- Первый экран: живая 3D-композиция — матовая керамическая тарелка с тремя роллами, имбирём и васаби. Палочки плавно поднимают один ролл и возвращают его на место; композиция слегка поворачивается за курсором. При reduced motion сцена статична.
- Для меню используются 13 сгенерированных фотореалистичных изображений WebP 720×720 в `public/sushi/`. Исходная 3D-студия доступна на `studio.html?kind=<вид>` (или `?kind=sheet` для всех сразу).
- Конвейер с роллами на цветных тарелках, как в кайтен-баре
- Меню: переключение категорий с «переезжающей» плашкой и анимированной перестановкой карточек
- Блюдо «летит» из карточки в корзину, счётчик подпрыгивает
- Выезжающая корзина, кольцо «45 минут», курьер на скутере
- Всё уважает `prefers-reduced-motion`

## Функциональность

- Корзина: количество, прогресс до бесплатной доставки, итог с доставкой
- Оформление заказа: имя, телефон с маской, адрес, валидация и экран «заказ принят»
- Изображения меню сгенерированы в едином ресторанном стиле; то же фото сета стоит на первом экране

## Стек

React 19, TypeScript, Tailwind CSS 4, Motion, three.js (React Three Fiber, drei), Vite.

## Запуск

```bash
npm install
npm run dev
```

Сборка в `dist/`: `npm run build`. Пути относительные — сборку можно выложить в любую папку, например на GitHub Pages.
